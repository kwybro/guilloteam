### What
A headless task management system (with a CLI).

### Why
Today's task management tools feel bloated, slow and increasingly irrelevant to the style of work that is emerging. On top of that, they trap your data in their systems. Software engineers, project managers, UI/UX designers and more are increasingly using agents like Claude Code, ChatGPT, and the like to help them with their work. But we're still reaching for tools like Jira to organize it all.
 
guilloteam is an open-source, lightweight system that turns work into data. As data, work can be served to the right people, visualized infinite ways, and allow contributions from anyone. The tool at its simplest is an API and a database. The second interface is a CLI. With it, humans and agents can create and manage projects/tasks through the command line and with natural language. Developers can spin up a couple of quick tasks, a designer can track long-running concepts, and a project manager can pull reports of any shape whenever they want. It's called guilloteam because it's headless - the user decides how they want to visualize the work - because it's just data. The "team" part is what makes work exciting. It's not about what you execute, but who you do it with.
